Qual tipo usar?

EAN-13 é o código dos produtos no varejo brasileiro (começa com 789 ou 790 para empresas registradas no Brasil). EAN-8 é a versão curta para embalagens pequenas. UPC-A é o padrão dos EUA e Canadá. Code 128 aceita letras e números e é muito usado em logística, patrimônio e etiquetas internas.

Nos códigos de produto, o último número é o dígito verificador: digite sem ele que o site calcula, ou com ele para conferir. Para vender em lojas, o código precisa ser registrado na GS1.
